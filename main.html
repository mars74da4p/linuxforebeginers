09 / КОРОТКИЙ СЛОВАРЬ

Термины, которые встретятся дальше

Дистрибутив
Собранная и поддерживаемая система на базе ядра Linux.
Репозиторий
Поддерживаемый источник пакетов программного обеспечения.
Rolling release
Модель обновления без крупных версий системы через несколько лет.
Init / PID 1
Первый пользовательский процесс; обычно управляет службами.
Демон
Фоновая служба, выполняющая системную или пользовательскую задачу.
Wayland
Протокол взаимодействия приложений с графическим композитором.
Пакетный менеджер
Инструмент для установки, обновления и удаления программ.
Live-система
ОС, запущенная с USB или диска без установки на компьютер.
Upstream
Исходный проект, откуда дистрибутив берёт и интегрирует компонент.
