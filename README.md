# Linux / Field Guide — путеводитель по системе[cite: 4]

Краткое руководство по Linux — "Linux изнутри", без лишних мифов. Это статическая одностраничная (single-file) справка, объясняющая устройство системы, историю, ядро, выбор дистрибутива, рабочие окружения и практические советы для пользователей[cite: 4].

Основной файл: `index.html` — откройте его в браузере, чтобы просмотреть интерактивную версию[cite: 2, 4].

## Что внутри[cite: 4]
Содержимое структурировано по разделам[cite: 4]:
- 01 · Карта системы — слои ОС (ядро, утилиты, службы, среда, приложения)[cite: 4]
- 02 · История и идеи — от GNU до современного Linux[cite: 4]
- 03 · Ядро — привилегии, память, драйверы и модель ядра[cite: 4]
- 04 · Дистрибутивы — подбор, сравнение и популярные семейства[cite: 4]
- 05 · Графика и среда — KDE, GNOME, Cinnamon, легкие WM и композиторы[cite: 4]
- 06 · Система — systemd, пакетные менеджеры, файловые системы и т.д.[cite: 4]
- 07 · Каждый день — практические советы до и после установки[cite: 4]
- 08 · Плюсы и нюансы — преимущества и возможные трудности[cite: 4]
- 09 · Короткий словарь — термины и определения[cite: 4]

## Особенности[cite: 4]
- Полностью самодостаточная статическая страница (html + встроенные стили и скрипты)[cite: 4].
- Боковая навигация с подсветкой активного раздела[cite: 4].
- Поиск по основным разделам[cite: 4].
- Интерактивный "подбор дистрибутива" с рекомендациями в зависимости от опыта, приоритета и железа (теперь с мгновенным пересчетом)[cite: 2, 4].
- Фильтры и карточки популярных дистрибутивов и окружений[cite: 2, 4].

## Как просмотреть локально[cite: 4]
1. Склонируйте репозиторий или скачайте файлы проекта.
2. Проще всего открыть `index.html` напрямую в браузере (двойной клик)[cite: 2, 4].
3. Если хотите поднять локальный HTTP-сервер:
   - Python 3: `python -m http.server 8000`
   - Откройте в браузере: `http://localhost:8000/index.html`[cite: 2, 4]

Файлы стилей и скриптов встроены в HTML-документы, внешние шрифты подгружаются с Google Fonts[cite: 1, 2, 4].
